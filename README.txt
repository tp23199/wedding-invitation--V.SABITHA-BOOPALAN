Mobile playback:
- The intro video starts muted on touch devices because mobile browsers block audible autoplay.
- Tap the video once to enable sound without pausing it.
- OPEN INVITATION appears when the video ends.
- The background MP3 starts when OPEN INVITATION is tapped and loops.

GitHub Pages:
1. Extract this ZIP.
2. Upload ALL files (not the ZIP itself) into the repository root.
3. Commit/push the changes.
4. In GitHub: Settings > Pages, select the correct branch and / (root), then Save.

Note: Mobile browsers and device settings control autoplay permissions. The first tap is required to enable video sound; no website can force sound autoplay before a user gesture.
